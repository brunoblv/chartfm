# ChartFM Design System
# Capítulo 10 — Hubs de Conteúdo (Artistas, Álbuns, Músicas e Reviews)

Versão 1.0

---

# Objetivo

Toda entidade do ChartFM deve ser um Hub.

Não apenas uma página.

Um Hub reúne:

informação

descoberta

comunidade

conteúdo

discussões

curadoria

estatísticas

e contexto.

Ao entrar em uma página, o usuário nunca deve encontrar apenas dados.

Ele deve encontrar motivos para continuar explorando.

# Resultado Esperado

Cada página do ChartFM deve parecer um universo próprio.

O usuário entra para consultar um álbum.

Acaba descobrindo uma Review.

Depois um autor.

Depois uma Community.

Depois outro artista.

Os Hubs deixam de ser páginas informativas.

Eles se tornam mecanismos permanentes de descoberta e interação.
