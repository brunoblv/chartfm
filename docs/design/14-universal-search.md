# ChartFM Design System
# Capítulo 14 — Busca Universal e Exploração

Versão 1.0

---

# Objetivo

A busca do ChartFM não serve apenas para encontrar.

Ela serve para descobrir.

O usuário deve conseguir iniciar qualquer jornada pela busca.

Ela é um ponto de entrada para todo o ecossistema.

---

# Filosofia

A maioria das buscas responde:

"Onde está isso?"

O ChartFM responde:

"O que mais pode interessar junto com isso?"

A busca nunca termina no primeiro resultado.

Ela inicia uma exploração.
