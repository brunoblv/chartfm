# ChartFM Design System
# Capítulo 7 — Sistema de Personalização e Descoberta

Versão 1.0

---

# Objetivo

O ChartFM não deve mostrar o mesmo conteúdo para todos.

A Home é personalizada.

As recomendações são personalizadas.

As páginas são personalizadas.

Até mesmo a ordem dos módulos pode mudar.

A plataforma deve aprender continuamente com cada usuário.

---

# Filosofia

A maioria das plataformas pergunta:

"O que é popular?"

O ChartFM deve perguntar:

"O que é interessante para esta pessoa?"

Essa pequena mudança altera completamente a experiência.

---

# Perfil Dinâmico

Nada é permanente.

Se o usuário passar três meses ouvindo Jazz, o algoritmo percebe.

Se depois migrar para Metal, o algoritmo evolui.

O perfil nunca fica congelado.

# Compatibilidade entre Pessoas

+

Recência

---

# Contexto

O algoritmo sempre deve considerar contexto.

Exemplo.

Usuário ouviu Paramore ontem.

Hoje.

Mostrar:

Hayley Williams.

Avril Lavigne.

Tonight Alive.

Stand Atlantic.

Não apenas artistas populares.

---

# Diversidade

Evitar bolhas.

A cada grupo de recomendações incluir conteúdo inesperado.

Exemplo.

80%

Conteúdo altamente relevante.

20%

Descobertas.

Esse equilíbrio incentiva exploração.

---

# Explicabilidade

Toda recomendação deve explicar sua origem.

Exemplos.

Porque você ouviu...

Porque você segue...

Porque você comentou...

Porque esta Community cresceu...

Porque esta Review recebeu muitas curtidas de pessoas parecidas com você.

A transparência gera confiança.

---

# Memória

O sistema lembra do histórico.

Exemplo.

Você ouviu este álbum há dois anos.

Hoje ele completa dez anos.

Pode ser uma boa hora para revisitá-lo.

---

# Descoberta

Camada 2

Camada 3

# Redescoberta

O ChartFM não deve mostrar apenas novidades.

Também deve lembrar músicas esquecidas.

Exemplo.

Você não ouve Linkin Park há oito meses.

Essa é uma recomendação tão valiosa quanto um lançamento.

---

# Intensidade

O algoritmo precisa equilibrar repetição.

Não mostrar sempre o mesmo artista.

Mesmo que seja favorito.

A Home deve respirar.

---

# Inteligência Editorial

Misturar dados com curadoria.

Exemplo.

Mesmo que um álbum não seja popular.

Se a equipe preparou um especial.

Ele merece destaque.

---

# Descoberta Social

As pessoas são a principal fonte de descoberta.

Priorizar:

Amigos.

Pessoas compatíveis.

Grandes curadores.

Autores de Reviews.

Moderadores.

A música chega através das pessoas.

---

# Objetivos do Algoritmo

Cada recomendação deve aumentar pelo menos um indicador.

Descoberta.

Leitura.

Comentários.

Seguidores.

Tempo na plataforma.

Retorno diário.

Se não aumentar nenhum deles, a recomendação perdeu valor.

---

# Evolução

O algoritmo nunca está pronto.

Toda interação do usuário melhora o modelo.

Quanto mais tempo utilizando o ChartFM, melhor a experiência.

---

# Resultado Esperado

Depois de alguns meses, dois usuários completamente diferentes terão Home completamente diferentes.

Não apenas conteúdos diferentes.

Mas ritmos diferentes.

Ordem diferente.

Destaques diferentes.

Pessoas diferentes.

Communities diferentes.

Cada Home torna-se uma representação da personalidade musical daquele usuário.

Essa personalização é o principal diferencial competitivo do ChartFM.
