# ChartFM Design System
# Capítulo 9 — Perfil do Usuário

Versão 1.0

---

# Objetivo

O perfil é a representação digital da identidade musical do usuário.

Ele não existe apenas para mostrar números.

Ele deve contar uma história.

Ao visitar um perfil, outra pessoa deve conseguir responder rapidamente:

Quem é essa pessoa?

O que ela gosta?

Como ela descobre música?

O que ela escreve?

Por que devo segui-la?

---

# Filosofia

Hoje, a maioria das plataformas mostra:

Número de plays.

Número de artistas.

Número de álbuns.

Fim.

O ChartFM deve mostrar personalidade.

O perfil deve parecer a casa musical daquele usuário.

---

# Resultado Esperado

O Perfil do ChartFM deve ser um dos maiores diferenciais da plataforma.

Ele não é uma página de estatísticas.

Ele é uma biografia musical viva.

Cada visita revela quem aquela pessoa é através da música.

O perfil deve ser tão interessante que o usuário tenha vontade de explorá-lo como exploraria o perfil de um artista ou de um grande crítico musical.
