VideoClipCover from chartfm. Use via `window.ChartFM.VideoClipCover` (bundle loaded from the root `_ds_bundle.js`).

## Examples

### Default

```jsx
() => <VideoClipCover seed={7} />
```

### Branded

```jsx
() => (
  <VideoClipCover paletteA="#FA243C" paletteB="#FFE66D" seed={3} width={360} />
)
```

### Compact

```jsx
() => (
  <VideoClipCover paletteA="#7B61FF" paletteB="#00C2FF" seed={12} width={200} />
)
```
